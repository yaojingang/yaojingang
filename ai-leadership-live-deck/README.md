# 《AI领导力》10问直播分享版

围绕直播间10个问题设计的浏览器原生演示文稿，共25页。内容包含开场铺垫、10组“问题现场 + 书中解法”、总结与新书行动页。

## 使用方式

1. 下载或克隆本仓库，保留本目录的完整结构。
2. 使用 Chrome、Edge 或 Safari 打开 `AI领导力-10问直播分享版.html`。
3. 使用方向键、空格、鼠标滚轮或触控手势翻页。
4. 鼠标移动到右侧可显示页面导航圆点，移动到右上角可显示全屏按钮。

- HTML、字体和图片均使用相对路径，整个目录可离线运行。
- 页面比例会自动适配常见桌面屏幕和短高度窗口。
